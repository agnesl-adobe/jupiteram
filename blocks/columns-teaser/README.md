# columns-teaser

Custom **columns** block. Purpose: Stacked image/text teaser rows with large circular images. One row per teaser, two cells each; put the image in the first or second cell to choose its side, so rows can alternate. Text cell: optional H2, bold fund name paragraph, description, CTA link.

## Authoring (Document Authoring)

Model: `standalone`

Single block table. Content: One row per teaser, same number of cells in every row; cells: Column 1 content (image or text) | Column 2 content (text or image).

## Supported variations

No variations.

## Universal Editor fields

- `columns-teaser` / `columns` (text): Columns
- `columns-teaser` / `rows` (text): Rows
- Cells use the shared `column` filter: text, image, button, title.


## Reuse guidance

Use for alternating image/text fund or product teasers. For generic multi-column layouts use columns.

Generated CSS is structural only; brand styling comes from the design pass.
